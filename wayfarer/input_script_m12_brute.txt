# Wayfarer Milestone 12 verification script (brute.c's two-hit brute,
# room (2,1)).
#
# Sequence: dismiss the title screen -> a short RIGHT hold at spawn
# (still on the enemy's own y=64 row, but stopping short of its 96-128
# patrol range) collects the sword pickup (Milestone 13) - without it,
# none of the swings below would do anything at all - then pivot up and
# away from that same row before crossing room (0,0), so the rest of
# this script's own contact-damage exposure comes only from the brute
# itself, not incidentally from Milestone 6's enemy -> cross east
# through (0,0) and (1,0) into (2,0) (held well past the real
# transition frame - room (2,0)'s own north/east walls safely pin the
# player there, no overshoot risk) -> cross south into (2,1) with a
# *precise*, non-overshooting DOWN hold (Milestone 16 opened (2,1)'s
# own south side too, leading to the new boss room (2,2) - the old
# "overshoot and let the closed wall clamp it" trick this script used
# to rely on would now walk straight through into that room instead,
# and did, until this script was fixed) -> approach the brute's
# vertical patrol column (BRUTE_X=64) and face right -> swing (frame
# 810, the real, empirically-found first overlap - scanned directly
# against the built ROM, not hand-computed from patrol math, same
# methodology input_script_m8.txt's own comments already document) for
# the first, non-lethal hit -> swing again at frame 820, deliberately
# only 10 frames later (inside BRUTE_HIT_COOLDOWN_FRAMES's own 20-frame
# window) - confirmed a genuine no-op (the brute stays at 1 HP, not
# defeated) - before the real second, lethal swing at frame 880
# actually defeats it.
#
# The exact working hit frames were found by an isolated per-frame
# scan against the real build (temporarily instrumented with a serial
# byte on each hit, removed again once the frames were confirmed) -
# not derived from BRUTE_MIN_Y/MAX_Y/BRUTE_HIT_COOLDOWN_FRAMES by hand.
# Re-derived twice now, both times because a later, unrelated map
# change (first Milestone 13's sword-pickup detour, now Milestone 16's
# new south exit from this same room) turned out to shift the working
# frames - confirmed empirically each time, never assumed to carry
# over from a plausible-looking uniform shift.
